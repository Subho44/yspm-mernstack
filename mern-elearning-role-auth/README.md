# MERN E-learning Role Based Authentication

## Features
- Admin / Student register login
- JWT authentication
- Admin can add course with image
- Admin can delete course
- Student/user can view and purchase course
- Responsive animated Bootstrap design

## Backend Run
```bash
cd backend
npm install
copy .env.example .env
npm run dev
```

## Frontend Run
```bash
cd frontend
npm install
npm run dev
```

## URLs
- Backend: http://localhost:5600
- Frontend: http://localhost:5173
